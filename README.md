````markdown
# Expense Tracker

A professional and responsive web-based Expense Tracker that helps users manage their income and expenses in a simple and organized way.

## Features

- Add income and expense transactions
- Track total balance
- View total income
- View total expenses
- Select transaction categories
- Add transaction dates
- Search transactions
- Delete transactions
- Data stored using Local Storage
- Responsive design for desktop, tablet, and mobile
- Clean and professional red-themed interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage

````

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/shoabk928-beep/Expense-Tracker.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

For development, you can also use the VS Code Live Server extension.

## How It Works

Users can enter a transaction with:

* Transaction title
* Amount
* Transaction type
* Category
* Date

The application automatically calculates:

```text
Balance = Total Income - Total Expenses
```

All transactions are saved in the browser's Local Storage, so the data remains available after refreshing the page.
